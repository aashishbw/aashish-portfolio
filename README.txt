For the static HTML/CSS/JS portfolio repository:
1. Upload blog.html, blog.css and blog.js to the SAME ROOT FOLDER as index.html.
2. Add a link to your existing blog card or blog section:
   <a href="blog.html">Read the full IT career guide →</a>
3. Commit changes in GitHub. Vercel should redeploy if connected.
4. Open https://YOUR-DEPLOYMENT-DOMAIN/blog.html

The page uses only HTML, CSS and JavaScript (plus a Google Fonts stylesheet).
It does not require Node.js or any paid service.

If your preferred published URL is a nested path, move the page to a folder
and update relative links to the homepage, CSS and JS accordingly.

SEO: canonical URL currently points to https://pdlaashish.com.np/blog.html.
Change it if the final public domain is different.
